# Nidha Hussain — Portfolio

A responsive, recruiter-focused portfolio with a bold editorial layout and sage/ivory visual identity.

## Files

- `index.html` — page content and structure
- `style.css` — responsive visual system and animations
- `script.js` — mobile navigation, current year and scroll reveal
- `assets/` — add your portrait and resume PDFs here

## Add your personal files

Place these exact files inside `assets/`:

- `profilephoto.jpeg`
- `NidhaHussain_CV.pdf` (technical resume)
- `nidha_product_cv.pdf` (product resume)

The page includes a styled fallback if the portrait is missing. Resume links will work once the two PDFs are added.

## Run locally

1. Open this folder in VS Code.
2. Use the Live Server extension, or open `index.html` in your browser.
3. Check the layout at desktop and mobile widths.

## Publish with GitHub Pages

1. Create a repository for the portfolio.
2. Upload the contents of this folder (not the parent folder itself, unless you intend that structure).
3. In repository Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`.
